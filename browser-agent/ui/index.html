متصفح مخصص لمواقع توليد الفيديو — تحكمك أنت في تسجيل الدخول
غير متصل

1. الاتصال الآمن

لا تضع هذا الرمز في GitHub أو في محادثة عامة. يحفظ في جلسة صفحة المتصفح الحالية فقط.

2. مواقعك المحفوظة

يسمح تلقائياً بالنطاق الأساسي ونطاقاته الفرعية. أضف نطاق تسجيل الدخول الخارجي فقط عند الحاجة، مثل مزود تسجيل الدخول الذي يستخدمه الموقع.

3. تسجيل الدخول وحفظ الجلسة

افتح الموقع، وسجّل الدخول بنفسك من الشاشة أدناه. يمكنك التعامل مع التحقق البشري أو رمز المصادقة بنفسك؛ الوكيل لا يتجاوز CAPTCHA أو وسائل الحماية.

لم تُفتح جلسة موقع بعد.

4. تعريف عناصر التوليد (مرة واحدة لكل موقع)

للتوليد الآلي الكامل يلزم ضبط حقل الوصف وزر التوليد وعنصر يدل على جاهزية النتيجة وزر التنزيل. يمكن اختيار المحددات المكتشفة من الصفحة بزر «استخدام».

5. توليد الفيديو بضغطة واحدة

اختر موقعاً واضبط محددات التوليد أولاً.
إصدار أولي قابل للتوسعة. توافر التوليد المجاني وحدوده وجودة النتائج تحددها المواقع نفسها، ولا يستطيع هذا الوكيل إنشاء رصيد GPU أو إلغاء قيودها.
